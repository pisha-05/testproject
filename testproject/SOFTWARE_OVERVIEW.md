# AccessRoute Live: Overview and Architecture

AccessRoute Live is an inclusive, multi-modal navigation platform designed to provide accessible and obstacle-aware transit routing in urban environments. While standard navigation systems prioritize vehicular travel times, AccessRoute Live focuses on pedestrians, wheelchair users, and commuters with mobility limitations. The application delivers step-free route guidance by tracking infrastructure accessibility metrics—including verified wheelchair ramps, slope gradients, and operational elevator and escalator statuses—ensuring users avoid physical barriers before encountering them on the street.

The routing engine works by evaluating paths across six distinct transit modes (wheelchair, walking, cycling, transit, driving, and emergency dispatch), tailoring speed and path selection to the constraints of each mode. For wheelchair and accessible transit modes, the system analyzes topological data to enforce maximum slope thresholds (keeping inclines under 5%) and automatically bypasses escalators or stairs in favor of certified lifts and ramps. In addition, the engine continuously monitors live events such as public rallies, barricades, and traffic congestion, recalculating ETAs and dynamically generating detour corridors around hazardous or crowded zones.

Under the hood, the application is built as a lightweight, zero-dependency web platform powered by an interactive Leaflet GIS interface, responsive UI components, and client-side routing algorithms. Real-time community intelligence is integrated through an interactive crowdsourced hazard modal, allowing users to report road obstacles, broken elevators, or waterlogging with instant community verification voting. A built-in telemetry simulation engine continuously pushes traffic fluctuations and obstacle updates to the map, while the Web Speech API delivers turn-by-turn voice prompts and a high-contrast mode ensures compliance with WCAG AAA accessibility standards.
