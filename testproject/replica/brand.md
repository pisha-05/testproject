# BRAND GUIDE & CODE SWEEP: ACCESSROUTE LIVE™

## 1. Brand Identity & Name Rationale
- **Official Name**: **AccessRoute Live™**
- **Tagline**: *"Navigation built around how YOU move."*
- **Core Mission**: Providing dignified, step-free, barrier-aware independent mobility to millions of pedestrians, wheelchair users, and families worldwide.
- **Brand Voice**: Empowering, Precise, Honest, Reassuring, Accessible.

---

## 2. Visual Language & Original Design System
- **Logo Concept**: Dynamic geometric route pin intertwined with a step-free continuous path loop.
- **Palette**:
  - `Royal Blue (#2563EB)`: Confident navigation primary.
  - `Safe Green (#059669)`: Verified ramps, elevators, and step-free certainty.
  - `Caution Amber (#D97706)`: Incline gradients, unverified reports.
  - `Hazard Red (#DC2626)`: Stairs, barricades, impassable obstacles.
  - `High Contrast Yellow (#FFFF00)` / `Deep Black (#000000)`: WCAG AAA compliance.
- **Typography**: Inter / System UI with high-legibility tabular monospace numerals for telemetry.

---

## 3. Brand Cleanliness Sweep
A complete sweep of the codebase was conducted to guarantee:
- **No Google Maps proprietary source code, hidden APIs, or private keys used.**
- **No Google logos, trademarked styling, or proprietary assets used.**
- **Pure OpenStreetMap / Carto / Esri open GIS cartography standards.**
- **Custom-engineered Step-Free Routing and Accessibility Penalty engine.**
